# Portfolio Matrix

Panel para analizar una cartera de inversión: posiciones y pesos, sectores, resultados, ingresos, impuestos estimados y proyección a 20 años.

- Es un único archivo (`index.html`). Se abre en cualquier navegador; no hay servidor.
- Los datos se guardan solo en tu navegador. Puedes importar el CSV de Trade Republic o escribir tus posiciones.
- «Actualizar precios» usa tu propia clave gratuita de Finnhub (se guarda solo en tu navegador).
